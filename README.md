# 🎨 מילון — ערבית מדוברת · v40

**גרסה מוכנה לפריסה בעיצוב כחול חשמלי, לבן ודיו כהה**, עם מבנה חדש שמעדיף חיפוש וקריאות. כל 6,132 הערכים ו־311 הפעלים מהגרסה המקורית כלולים. אין צורך בשרת יישומים, בסיס נתונים, מפתח API או התקנת חבילות לצורך השימוש.

## 🚀 העלאה לאתר

חלץ את ה־ZIP והעלה את **שבעת הקבצים הבאים מאותה תיקייה** למיקום של המילון הקיים, במקום הקבצים הישנים:

```text
index.html
sw.js
manifest.json
icon.svg
icon-192.png
icon-512.png
icon-maskable.png
```

**יש להעלות את כולם יחד**, באותו נתיב שבו פעלה הגרסה הקודמת. הכתובות יחסיות ומתאימות גם לתת־תיקייה כגון `/milon-aravit/` ב־GitHub Pages. הפעלת PWA ואופליין דורשת HTTPS, או localhost לצורך פיתוח.

פתח את האתר כשהמכשיר מחובר לרשת והמתן לטעינה הראשונה. כשהעותק זמין לאופליין מופיע הכיתוב ״עובד אופליין״. אם פתוחה גרסה ישנה, רענן והמתן לעדכון. שינוי האייקון של קיצור דרך קיים עשוי להיות תלוי בדפדפן ובמערכת ההפעלה.

פתיחת `index.html` ישירות מהמחשב מאפשרת שימוש בממשק ובחיפוש; במצב `file://` אין Service Worker או התקנת PWA.

## ✨ מה כלול

- עיצוב מלא לנייד ולמחשב: טיפוגרפיה עברית־ערבית, לוגו ואייקונים חדשים, חיפוש נגיש בגלילה, כרטיסים לבנים ומסך מילה כהה.
- מסך מילה עם תעתיק גדול, נטיות עבר/הווה/ציווי, דוגמאות וקישורים קיימים למקורות הגייה.
- תצוגת הווה ראשונית עם כל שמונת הגופים ואפשרות לתצוגה מקוצרת; בציווי שלושת הגופים מוצגים במלואם.
- כל 41 הקטגוריות נגישות דרך שמונה קבוצות פתוחות, עם חיפוש לפי נושא; קטגוריות הנתונים המקוריות נשמרו.
- חיפוש בערבית, בעברית ובתעתיק, כולל צורות נטויות והצעות לכתיב קרוב.
- שמורים וקישור נפרד לכל משמעות, בלי לערבב ערכים בעלי כתיב זהה.
- בקשות להוספת מילים נשמרות **רק אחרי לחיצה מפורשת** ומיוצאות לקובץ JSON. אין שליחה לשרת.
- פונטים מוטמעים ב־HTML, תמיכה בהעדפת הפחתת תנועה וניווט מקלדת בחלון הפרטים ובטאבים.

## 🔄 תאימות לשמורים ולקישורים

השמורים הקודמים מועברים בעת פתיחת הגרסה החדשה **באותו origin ובאותו פרופיל דפדפן**. אם לכתיב יש כמה משמעויות, נשמרות כולן ומוצגת הודעה במסך השמורים. אפשר להסיר את המשמעות שאינה נחוצה. מפתח השמורים הישן אינו נמחק.

קישורי `#w=...` הישנים עדיין נתמכים. כאשר הם עמומים נפתחת בחירת משמעות. קישורים חדשים משתמשים ב־`#entry=w.....` ובמזהים קבועים הנשמרים עם הנתונים.

## 🛠️ קובצי המקור

הקבצים המוכנים כבר בנויים — אין צורך להריץ דבר כדי להעלות אותם. התיקיות הנלוות מיועדות לתחזוקה:

```text
src/                     תבנית HTML, עיצוב, חיפוש וקוד הממשק
docs/dictionary.json     מקור הנתונים הקנוני עם מזהים קבועים
docs/CHANGELOG.md         פירוט שינויים ומגבלות
docs/QA.md                מה נבדק ומה דורש בדיקה במכשיר
docs/SPEC-v38.md           האפיון ההיסטורי המקורי
tools/build.cjs           בנייה ועדכון אוטומטי של גרסת המטמון
tools/test.cjs            בדיקות נתונים, חיפוש ו־SW
tools/ui-smoke.cjs        הרצת הממשק בסביבת DOM מדומה
```

לשינוי עתידי, ערוך את `src/` או `docs/dictionary.json` ואז הרץ עם Node.js 20 ומעלה:

```bash
node tools/build.cjs
node tools/test.cjs
node tools/ui-smoke.cjs
```

אין תלויות npm. הבנייה מעדכנת את `index.html`, `sw.js` ואת `docs/release.json`. אין לערוך את ה־HTML המופק ידנית: בנייה מחדש תחליף את השינוי. אייקוני PNG הם תוצרים מוכנים; שינוי הלוגו דורש יצירת PNG חדשים מה־SVG לפני הבנייה.

**אין למחוק, לייצר מחדש או למחזר מזהים קיימים** בעת עריכת מילים. אין בחבילה זו מימוש של כלי מיזוג תוכן חדש; תהליך אימות לשוני מלא נשאר עבודה נפרדת.

## ⚠️ גבולות הבדיקה

התוכן הלשוני נשמר כפי שסופק, כולל שתי הערות עבריות שבהן מופיע ציטוט בערבית. אין כאן הצהרה שכל התוכן עבר הגהה לשונית. ההשמעה ממוחשבת ואינה מבטיחה להג פלסטיני; מקורות ההגייה החיצוניים דורשים רשת. החיפוש, הטקסט והנטיות זמינים אופליין לאחר שמירת האפליקציה.
