## יכולות

- **חיפוש בשלוש שפות** — ערבית, עברית ותעתיק עברי, עם או בלי ניקוד
- **חיפוש בצורות נטויות** — הקלדת `بيفتح` מוצאת את `فتح` ומציינת שזו צורת הווה
- **נטיות בטאבים** — עבר / הווה / ציווי
- **קישורי שורש** — מעבר בין מילים מאותו שורש (זיהוי אוטומטי משוער)
- **שמורים** — סימון מילים לחזרה
- **אופליין מלא** — כולל הפונטים. אפס בקשות רשת.

## ⚠️ עדכון גרסה

בכל העלאה של `index.html` מעודכן, יש להעלות גם את מספר הגרסה ב-`sw.js`:

```js
const CACHE_VERSION = 'milon-aravit-v9';   // →  v10, v11 ...
```

בלי זה, מי שכבר התקין ימשיך לקבל את הגרסה הישנה מהמטמון.

## הוספת מילים

כל הנתונים במשתנה `DICTIONARY` בתוך `index.html`.

```js
{ ar:"فتح", tr:"פַתַח", he:"פתח", cat:"פעלים - נטיות",
  ex:[{ar:"...", he:"..."}],            // רשות
  conj:[...], pres:[...], imp:[...] }   // פעלים בלבד
```

- `conj` (עבר) ו-`pres` (הווה) — 8 גופים בסדר: אני, אתה, את, הוא, היא, אנחנו, אתם, הם
- `imp` (ציווי) — 3 גופים: אתה, את, אתם
- `pres` כולל את תחילית ה-**ب** המדוברת (`بفتح` ולא `أفتح`)
- `cat` — עדיף לבחור מ-41 הקטגוריות הקיימות

אחרי כל עריכה יש לוודא תקינות JS לפני העלאה — שגיאת תחביר אחת שוברת את כל האפליקציה.

## עיצוב

**אינדיגו וזעפרן** — שני הצבעים היקרים ביותר של הלבנט.
אינדיגו צבע את הבדים, זעפרן היה שווה משקלו בזהב.

- רקע `#0C0F22`, אקסנט `#E9B558`
- טיפוגרפיה: **Noto Naskh Arabic** (ערבית), **Assistant** (עברית)
- הפונטים **מוטמעים כ-base64** אחרי חיתוך לתווים שבשימוש: 116KB → 77KB (רק 2 פונטים בפועל)
