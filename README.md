# מילון ערבית מדוברת ↔ עברית

אפליקציית מילון אופליין ללהג הפלסטיני.
**1,399 ערכים · 75 פעלים** עם נטיית עבר, הווה וציווי מלאה.

## יכולות

- **חיפוש בשלוש שפות** — ערבית, עברית ותעתיק עברי, עם או בלי ניקוד
- **חיפוש בצורות נטויות** — הקלדת `بيفتح` מוצאת את `فتح` ומציינת שזו צורת הווה
- **נטיות בטאבים** — עבר / הווה / ציווי
- **קישורי שורש** — מעבר בין מילים מאותו שורש (זיהוי אוטומטי משוער)
- **מועדפים** — סימון מילים לחזרה
- **מצב כהה** ואופליין מלא

## קבצים

| קובץ | תפקיד | מתעדכן? |
|---|---|---|
| `index.html` | האפליקציה כולה — מאגר, חיפוש, עיצוב | ✅ בכל סבב מילים |
| `manifest.json` | שם, אייקון וצבע להתקנה במסך הבית | ❌ פעם אחת |
| `sw.js` | Service Worker — עבודה אופליין | ⚠️ רק מספר הגרסה |
| `icon.svg` | אייקון האפליקציה | ❌ פעם אחת |

## הפעלה ב-GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)**
4. עד 10 דקות לפרסום, ואז Visit site

הריפו חייב להיות **Public** בחשבון חינמי.

## ⚠️ עדכון גרסה

בכל העלאה של `index.html` מעודכן, יש להעלות גם את מספר הגרסה ב-`sw.js`:

```js
const CACHE = 'milon-v1';   // →  'milon-v2', 'milon-v3' ...
```

בלי זה, מי שכבר התקין ימשיך לקבל את הגרסה הישנה מהמטמון.

## הוספת מילים

כל הנתונים במשתנה `DICTIONARY` בתוך `index.html`.

```js
{ ar:"فتح", tr:"פַתַח", he:"פתח", cat:"פעלים - נטיות",
  ex:[{ar:"...", he:"..."}],            // רשות
  conj:[...], pres:[...], imp:[...] }   // פעלים בלבד
}
```

- `conj` (עבר) ו-`pres` (הווה) — 8 גופים בסדר: אני, אתה, את, הוא, היא, אנחנו, אתם, הם
- `imp` (ציווי) — 3 גופים: אתה, את, אתם
- `cat` — עדיף לבחור מ-41 הקטגוריות הקיימות ולא ליצור חדשה

אחרי כל עריכה יש לוודא תקינות JS לפני העלאה — שגיאת תחביר אחת שוברת את כל האפליקציה.
