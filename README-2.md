# מילון ערבית מדוברת ↔ עברית

אפליקציית PWA אופליין ללהג הפלסטיני: **1,399 ערכים** ו־**75 פעלים** עם נטיית עבר, הווה וציווי.

## יכולות

- חיפוש בערבית, בעברית ובתעתיק — עם או בלי ניקוד
- חיפוש בצורות נטויות, כולל הסבר כמו `הווה · הוא`
- אינדקס חיפוש שנבנה פעם אחת ו־debounce של 150ms
- נטיות בטאבים, דוגמאות שימוש וקישורי שורש
- מועדפים, 41 קטגוריות עם ספירות ומצב כהה
- הקראה בערבית וקישורים ל־YouGlish ול־Forvo
- עבודה אופליין מלאה ובאנר עדכון לגרסה חדשה
- ממשק RTL נגיש ורספונסיבי

## הקבצים להעלאה

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה ומאגר המילים |
| `manifest.json` | הגדרות ההתקנה של ה־PWA |
| `sw.js` | מטמון אופליין ועדכוני גרסה |
| `icon.svg` | לוגו וקטורי |
| `icon-192.png` | אייקון התקנה 192×192 |
| `icon-512.png` | אייקון התקנה 512×512 |
| `icon-maskable.png` | אייקון Maskable בגודל 512×512 |

יש להעלות את כל שבעת הקבצים **לאותה תיקייה** בשורש הריפו.

## הפעלה ב־GitHub Pages

1. מעלים את הקבצים לריפו `milon-aravit`.
2. נכנסים אל **Settings → Pages**.
3. בוחרים **Deploy from a branch**.
4. בוחרים `main` ואת התיקייה `/ (root)`.
5. פותחים `https://rotemmalky.github.io/milon-aravit/` דרך HTTPS.

לאחר ההעלאה הראשונה מומלץ להסיר Service Worker ישן דרך DevTools או לבצע טעינה מחדש, כדי שהגרסה החדשה תשתלט.

## עדכון גרסה

בכל עדכון של `index.html`, משנים את הערך הבא ב־`sw.js`:

```js
const CACHE_VERSION = 'milon-aravit-v2';
```

לדוגמה: `v2` → `v3`. משתמשים שכבר התקינו יקבלו באנר **„גרסה חדשה זמינה”**.

## מבנה הנתונים

המאגר נמצא במשתנה `DICTIONARY` בתוך `index.html`. אין לשנות את מבנה המערך ללא בדיקת JavaScript מלאה.

```js
{ ar:"فتح", tr:"פַתַח", he:"פתח", cat:"פעלים - נטיות",
  ex:[{ar:"...", he:"..."}],
  conj:[...], pres:[...], imp:[...] }
```

`conj` ו־`pres` מכילים שמונה גופים; `imp` מכיל שלושה גופים.

## עיצוב

הלוגו מחבר את האות הערבית `ع` והאות העברית `ע`, עם גרש שמייצג את שכבת התעתיק. הפלטה מבוססת Petrol עמוק, לבן קריר וענבר. אין פונטים, ספריות או משאבים חיצוניים.
